# Link

ลิงก์ในข้อความ ใช้สี `brand` (ฟ้า) hover เป็น `brand-hover`

## การใช้
- ใช้ `.link` กับ `<a>` ที่อยู่ในเนื้อหา
- **ขีดเส้นใต้เสมอ** ไม่ใช้สีอย่างเดียวบอกว่าเป็นลิงก์ (สีฟ้า `brand` ต่างจากสีตัวอักษร `text` ไม่มากพอสำหรับคนที่มองสีไม่ชัด)
- คอนทราสต์ของ `brand` เป็นตัวอักษร: 4.95:1 บน `surface`, 4.66:1 บน `surface-sunken` ผ่าน AA ทั้งคู่ แต่ **บน `tint-sky` เหลือ 4.16:1 ไม่ผ่าน** ให้ใช้ `brand-hover` (6.11:1) ถ้าต้องวางลิงก์บนพื้นนั้น
