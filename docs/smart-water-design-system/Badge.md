# Badge

ป้ายสถานะสำหรับผลการจับคู่ scenario — ตรงกับ 3 สถานะจริงของโปรเจกต์

## การใช้
- `.badge-success` = พบ scenario ที่ตรง, `.badge-warning` = ความมั่นใจต่ำ/จับคู่บางส่วน, `.badge-danger` = ไม่พบข้อมูลที่ตรง (no-match)
- **ทุกอันต้องมีสัญลักษณ์นำหน้าข้อความเสมอ** (✓ / ! / ✕) ห้ามใช้สีอย่างเดียวสื่อสาร — success (เขียว) กับ danger (แดง) เป็นคู่ที่คนตาบอดสีแยกยากที่สุด เป็นเงื่อนไขที่ตั้งไว้ตั้งแต่ตอนกำหนด token
