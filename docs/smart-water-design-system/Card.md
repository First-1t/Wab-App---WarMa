# Card

กล่อง container พื้นฐานสำหรับแต่ละ step ของหน้า wizard

## การใช้
- โครงสร้าง: ตัวบอกลำดับ step (ใช้ได้เพราะ wizard เป็นลำดับจริง) → หัวข้อ → เนื้อหา → footer ที่มีปุ่ม
- padding ใช้ `space-4` และมุมใช้ `radius-md` — ตรงกับ usage note ของ token ทั้งสองตัว และทำให้ปุ่มกับการ์ดมีมุมชุดเดียวกัน

## ยังไม่ทำ (รอบถัดไป)
- Progress indicator ข้าม step แบบภาพ (ตอนนี้มีแค่ข้อความบอกลำดับ)
