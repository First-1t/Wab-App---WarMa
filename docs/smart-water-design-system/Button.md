# Button

ปุ่มหลักสำหรับ action ต่างๆ ในเว็บ มี 3 แบบ (primary/secondary/outline) และ 2 ขนาด (lg/sm)

## การใช้
- `.btn-primary` ใช้ `text` เป็นสีตัวอักษร ไม่ใช่ขาว — `primary` (#65B741) สว่างเกินกว่าตัวอักษรขาวจะอ่านออก (2.5:1) ส่วนตัวเข้มได้ 5.87:1
- `.btn-secondary` ใช้ตัวอักษรขาวได้ตามปกติ (5.0:1)
- `.btn-outline` (ฟ้าแบบขอบ ตัวอักษรสี `brand` 4.95:1) ใช้ **วางคู่กับปุ่มเขียวในหน้าเดียวกัน** เช่น หน้าเปรียบเทียบ scenario เพื่อไม่ให้ปุ่มทึบสองสีแย่งความสนใจกัน และให้ปุ่มเขียวเป็นปุ่มหลักของหน้าเพียงปุ่มเดียวเสมอ hover ใช้ `brand-hover` + พื้น `tint-sky` (6.11:1 — ห้ามใช้ `brand` บนพื้นนี้เพราะเหลือแค่ 4.16:1) ขนาดเท่าปุ่มทึบเป๊ะ เพราะขอบทำด้วย inset shadow ไม่ใช่ border
- `.btn-lg` = ปุ่มหลักของหน้า, `.btn-sm` = ปุ่มรองในพื้นที่แคบ เช่นใน Card
- Hover ผูกกับ `primary-hover` / `secondary-hover` ไว้แล้วในคลาสนี้ ไม่ต้องเขียนเพิ่ม

## ยังไม่ทำ (รอบถัดไป)
- Disabled state
- ปุ่มไอคอนอย่างเดียว (icon-only)
