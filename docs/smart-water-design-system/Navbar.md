# Navbar

แถบเมนูด้านบน พื้นสี `brand` (ฟ้า) ตัวอักษรขาว (4.95:1) — ตามพาเลตแรกของทีมที่ให้ Navbar อยู่ในกลุ่มสีหลัก

## การใช้
- ครอบด้วย `<nav class="navbar" aria-label="...">` ใส่ชื่อระบบใน `.navbar-title` (ดันเมนูที่เหลือไปชิดขวาอัตโนมัติ) แล้วตามด้วยลิงก์
- หน้าที่เปิดอยู่ใส่ `aria-current="page"` — ตัว CSS จะตัวหนา + ขีดเส้นใต้สีขาวให้เอง
- **ห้ามใช้สีเขียวเป็นตัวบอกเมนูที่เลือกบนแถบนี้** เขียว (#65B741) บนฟ้า (#1D74B8) ได้แค่ 1.98:1 ซึ่งต่ำกว่า 3:1 ที่ต้องมีสำหรับตัวบ่งชี้ UI จึงใช้ขีดสีขาวแทน
- บนมือถือ เมนูจะตัดบรรทัดลงมาเองเมื่อแคบ (`flex-wrap`) ยังไม่มีเมนูแฮมเบอร์เกอร์

## ยังไม่ทำ (รอบถัดไป)
- เมนูพับสำหรับมือถือ (hamburger)
- ปุ่ม CTA เขียวบน Navbar
